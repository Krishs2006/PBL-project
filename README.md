# 🎓 SAGE Campus Event Hub

A professional web-based university event management system developed using HTML, CSS and JavaScript.  
This platform helps students from different departments explore, discover and register for campus events easily.

---

# ✨ Features

- Student Login System
- Admin Login System
- Dynamic Event Dashboard
- Department-wise Event Filtering
- Event Registration System
- Search Functionality
- Dark Mode Support
- Responsive User Interface
- Admin Event Management
